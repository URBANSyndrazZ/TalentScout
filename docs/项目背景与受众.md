## 0. 一句话

**被埋没的人，值得一次不看出身的机会。**

把"认可"从一个靠出身、靠关系、看不见、也没法验证的东西，变成公开、有成本、可校验的市场——**社区先选，企业再看**。

> 开场洞察（路演第一句）：**最了解一个工程师水平的，不是 HR，也不是算法——是和他一起写过代码的人。** 但这句话今天说不出口，因为没有一个地方能把它公开记下来。我们做了这个地方。

---

## 1. 为什么做这个项目

### 1.1 求职者这一侧：努力没有被"可验证地"记录

- 简历是**自我声明**：写了什么、有多少分量，招聘方无法快速判断，只能靠学历和大厂标签做代理指标。
- 投递是**单向黑洞**：投出去没有反馈，也没有"有人认可我"的公开痕迹。
- web3 尤其明显：大量真实能力产生在**开源仓库、黑客松、社区答疑**里，但这些贡献没有一个能被招聘方"一眼看到"的地方。
- 结果是：**没有名校/大厂背书的人，天生少一次被看见的机会。**

### 1.2 社区 / 活动主办方这一侧：人才是社区的产出，却散场即归零

- 一场黑客松 200 人，真正能打的可能只有 20 个。活动结束，微信群静下来，**这批人的信号就没了**。
- 主办方手里最有价值的资产（人才名单 + 谁被同行认可）从来**没有被沉淀、也没有被定价**。

### 1.3 企业 / 星探这一侧：拿到的信号太少，且不可信

- 传统渠道给企业的是一份简历；**"同行愿不愿意为这个人站台"这类信号完全缺失**。
- 现有的"点赞 / 内推"信号全部藏在平台后台：**可以刷、不可审计、无法追溯**，企业不敢真的拿它做决策。

### 1.4 根本矛盾

> 招聘市场里的"人气"和"背书"，**在没有成本、无法公开验证的时候，就一定是廉价的**。

---

## 2. 我们的解法

**两层漏斗：先让人被看见（广度），再让人被认可（深度）。**

| 层 | 机制 | 解决什么 |
| --- | --- | --- |
| **先被看见** | 免费投票，1 地址 1 票、不可自投 | 让被埋没的人先有热度——**而热度买不到** |
| **再被认可** | 打赏 MON / 0.01 MON 付费留言（**带署名 + 交易哈希**） | 同行的公开背书——**有成本、可追责、可验证** |

**为什么不是单纯"大众认可"**：大众认可 ≠ 专业能力，很容易变成比人缘、比营销。真正能替代"内推"的，是**同行愿意公开站台**——"我跟他一起写过合约，他做事靠谱"这句话，比一百个赞有价值。所以我们的设计是：**免费票负责让人被看见，付费留言负责让人被认可**，两者缺一不可，也不能互相替代。

把"候选人竞争"这件事拆成**三层互相独立、不可互相替代的信号**，全部上链：

| 层次 | 机制 | 解决什么 | 为什么这样设计 |
| --- | --- | --- | --- |
| **人气** | 免费投票，1 地址 1 票、不可自投 | 谁被更多人看见 | 人气**不能被钱买断**，否则榜单一无是处 |
| **支持** | 打赏任意金额 MON，100% 归候选人 | 谁愿意真金白银站台 | 免费表态是廉价的；**有成本的支持才有信息量** |
| **背书** | 付费留言 0.01 MON，永久上链 | 给候选人的公开评价 | 定额费防垃圾；留言是候选人**最好的面试预演** |

叠加两个机制：

- **阈值入池**：票数 ≥ 阈值 → 自动点亮"已入池"，进入**推荐池**（企业视角的候选名单）。
- **链上简历**：基本信息与简历写在独立的 ProfileRegistry，**内容哈希上链、本人可更新、历史留痕**。任何人拿到一份简历，都能用它验证"这份和当初上链的那份是不是同一份"。

> 一句话：**链上的社交信号不可变，简历资料可编辑但留痕。** 两类数据分离，各司其职。

## 3. 目标受众

### 3.1 求职者（核心用户）

**谁**：web3 新人、独立开发者、转行者、没有名校/大厂标签但手里有真实作品的人。

**他要什么**：一次不依赖关系、可以被看见的机会。

**他怎么用**：
1. 链上发布自荐卡（名字 + 一句话 + 技能 + 主题色）——一笔交易，像发一条动态一样轻；
2. 填链上简历（期望岗位 / 城市 / 经验 / 教育 / 经历），内容哈希留痕；
3. 把卡片链接丢进社群——**每一次支持都公开、付费、不可篡改**。

**他得到什么**：不只是一票，而是"有人愿意为我站台"的公开证据，以及票数达标后进入推荐池。

### 3.2 社区与活动主办方（增长引擎）

**谁**：黑客松主办方、DAO、技术社区、高校区块链社团。

**痛点**：活动结束 = 人才散场，社区最有价值的资产流失。

**价值**：一套可白标的"人才墙"——活动期间全员参与打榜，**活动结束后沉淀下来的是一份链上人才库**，而不是一堆群聊记录。

### 3.3 企业 / 星探 / HR（付费方）

**谁**：招 web3 岗位的创业公司、猎头、生态基金的人才负责人。

**痛点**：想提前发现人，但只能等到简历递上来；社区里的口碑信号看不见。

**价值**：推荐池里是**已经被一群陌生人验证过的人**，且每一条验证记录都在链上可查；企业可公开标记意向，形成可追溯的接触记录。

### 3.4 围观者 / 同行（低成本参与者）

**谁**：同场活动的人、朋友、社区成员。

**价值**：免费投票只要 gas；0.01 MON 就能给朋友留一句公开的站台话——**参与成本低到没有理由不参与**，而这恰好撑起了整个信号市场。

## 4. 为什么必须是 Monad

不是"为了上链而上链"，这三个点离开 Monad 都不成立：

1. **微支付在经济上才可行**：留言费 0.01 MON、打赏 0.05 MON 级别——这个量级的手续费只有在高吞吐、低单价的链上才不荒谬。支持一位候选人的动作，**成本必须低于发一条付费消息**。
2. **信号要"当场"变成反馈**：实测 Monad 测试网出块约 **0.33 秒**（前端角标实时显示）。台上有人投票，大屏几秒内就变——**链上互动第一次像 Web2 一样跟手**。
3. **场景本身就是高频互动**：一场活动几百人同时打榜、留言、标记意向，是典型的**高并发小交易**场景，正是 Monad 的设计目标。

## 5. 商业逻辑与可持续性

**核心原则：不向求职者收钱。** 求职者是供给，向供给收费会立刻杀死网络效应。

| 收入来源 | 说明 | 冷启动策略 |
| --- | --- | --- |
| **企业侧订阅 / 意向付费** | 企业为"进入推荐池视图 + 发起意向"付费 | 首年免费，先做候选人与活动侧规模 |
| **活动白标** | 每场黑客松 / 训练营 / 招聘会一套定制人才墙 | 从 Monad 生态活动开始，一场一场签 |
| **成功撮合分成** | 入职确认后按比例结算，可用链上托管自动执行 | 只在成交后收费，B 端无风险 |

留言费与打赏 **100% 归候选人**，平台不抽成——这是可以公开写在合约里的承诺（`withdraw` 由候选人自己调用）。

### 5.1 求职者为什么要把简历放上来？他拿到什么？

**先说残酷的前提：求职者不会为了"链上"来，也不会为了"投票"来——他们只为"拿到面试/offer"来。** 所以这个产品对求职者的价值，必须落在这句话上：**它能不能提高我被招到的概率。**

能，通过三件 Boss 直聘给不了的事：

| 拿到什么 | 具体是什么 | 为什么别处拿不到 |
| --- | --- | --- |
| **① 一份可携带、可验证的背书资产** | 30 个陌生人的投票 + 3 家企业的意向 + 若干条实名留言，全部上链、永久、带哈希 | 招聘平台里的"沟通记录/点赞"是**平台私产**，换平台就清零。这里的记录**不属于任何平台**，你可以贴给任何人看，且对方能当场校验 |
| **② 一次不看出身、只看作品的曝光机会** | 票数就是曝光排序，靠的是"你的作品和一句话有没有打动人" | 没有名校/大厂标签的人，唯一的困境是"没人看得到"。这个机制**把出身从排序公式里删掉了** |
| **③ 一次公开的面试预演** | 你能看到谁支持了你、留言说了什么、几家企业标记了兴趣 | 传统投递是黑洞，投出去没有反馈。这里的反馈是公开的、带署名的——"我跟他一起写过合约，他做事靠谱"比任何推荐信都硬 |

**但必须承认：这三条只有在"有人真的在看"时才成立。** 所以冷启动的解法是**从活动切进去**——黑客松现场本身就有企业、评委、同行在扫，**活动结束时你的曝光、留言、背书记录已经兑现了**，不需要等企业上线。这是这个模式能启动的关键：**社交收益即时兑现，招聘收益延迟兑现。**

**同时要承认摩擦**：现在"连钱包 → 发卡 → 填简历"三步仍然是门槛。真正让求职者愿意粘简历的前提是**把这三步压到一次点击**（内嵌钱包 + 社交登录），这是 roadmap 的第一条，不是可选项。

### 5.2 投资者拿到什么？

分三类资金，三类拿的东西不一样：

**① 公链生态基金（最容易拿到的钱）——投的是"开发者增长"**

对 Monad 生态来说，TalentScout 是**给生态输送开发者的基础设施**：黑客松是公链获取开发者的主要手段，而这个项目把每场黑客松的产出**沉淀成链上资产和可复用的人才库**。生态基金投的从来不是"这个 app 的现金流"，而是"生态的开发者数量与留存"——**这条逻辑对整个生态的贡献是直接的**，所以是第一个该找的钱。

**② 财务型 VC —— 投的是"高客单价行业的抽成权 + 稀缺数据"**

- **招聘是高毛利行业**：猎头按成功入职拿 20% 年薪。撮合分成一旦跑量，单位经济极好，而且**链上托管让分成自动执行、不需要信任平台**。
- **稀缺资产是那张"谁被谁认可"的图谱**：链上的背书关系是公开、可组合的，而 LinkedIn 的关系数据是封闭的。**每多办一场活动，这张图谱就厚一层，且它是别人抄不走的存量**。
- **可预测的 B 端收入**：活动白标是订阅式收入，而且从 Monad 生态的活动开始签——**渠道天然现成**。

**③ 战略/产业资本 —— 投的是"活动—人才库—招聘"这条转化链**

故事是三段式：**先把活动场景做实（可复制、可签单）→ 积累人才库与背书图谱（数据护城河）→ 再往招聘撮合走（高客单价变现）**。投资人真正下注的是**第一段到第二段的转化能力**——能不能一场一场地把活动签下来。

### 5.3 这个模式最容易被问倒的三个地方（以及我们的答法）

| 质疑 | 诚实的回答 |
| --- | --- |
| **"企业和候选人可以在链下成交，绕过你的抽成"** | 会。所以我们的收费点不能是"见面的过路费"，而必须是**绕不开的东西**：链上存证的可验证背书、意向存证的公开记录、托管分成的"不成交不收费"。 |
| **"招聘行业链上化一直做不起来，为什么你能成？"** | 因为我们不碰最难的那段（真实姓名、背调、offer 流程），只做**最上层、最轻、最社交的那段**：发现与背书。求职者在这里暴露的成本极低。 |
| **"双边市场冷启动"** | 我们的答案是**从活动切**：活动自带几百人和明确的时间窗，不需要先有企业。这也是为什么第一笔收入来自活动主办方，而不是企业。 |

## 6. 我们不做什么（划清边界，避免过度承诺）

- ❌ **不做履历真伪验证**：链上存的是"这个人自己写的 + 有哈希留痕"，不是"权威机构认证过的"。真伪验证是另一条产品线。
- ❌ **不做完整招聘闭环**（ATS、面试排期、offer 流程）：我们做的是**漏斗最上层的发现与验证**。
- ❌ **不做代币激励**：任何"刷量得币"的设计都会把信号污染成刷单，与人气榜的初衷相悖。
- ❌ **不承诺"直推大厂"**：落地的是**推荐池 + 意向存证**，真实对接需要企业侧参与。

## 7. 与同类/往期的差异

据对本社区往期 **200 个 Monad 项目**的全量扫描（详见 `knowledge/past-projects/`）：

- **求职 / 招聘 / 候选人方向**：全库仅 3 个弱关联项目，且都不是"人选市场"（分别是学习网站的未来规划、经历验证钱包、外包贡献凭证）。**本方向是空白。**
- **付费留言 / 打赏墙**：仅有一个创作者打赏项目，**无"给候选人付费留言"**。
- **最接近的邻居**是"社区需求墙 + 0.01 MON 点亮支持"类项目——差异点在于我们是**人物卡 + 免费票/付费支持双层信号 + 阈值入池 + 企业意向**的完整招聘漏斗，而不是一面留言墙。

收入：企业意向付费 / 活动白标 / 成功撮合分成 —— 永不向求职者收费
